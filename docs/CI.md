# Continuous integration

GitHub Actions checks the Android build, installer tests, Java settings logic, 100% line and branch coverage for project-owned pure logic, formatting, documentation links, and the no-runtime-network policy. Third-party GitHub Actions are pinned to full commit SHAs.

The project does not configure paid or credential-gated code-rating providers. A badge is included only for a workflow that runs in this repository. Aikido and Scrutinizer are not used.
