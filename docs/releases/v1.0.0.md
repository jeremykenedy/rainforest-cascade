# Rainforest Cascade 1.0.0

First stable release of the animated waterfall screensaver for Fire TV, Android TV, and Google TV.

## Included

- Continuously animated waterfall, cliffs, foam, pool currents, and optional rising mist.
- Rainforest, mossy stone, and red canyon environments.
- Day/night lighting, waterfall width, flow speed, mist density, optional sunlight shimmer, and random choices.
- Remote-friendly settings and versioned host settings provider.
- Guided release installer with SHA-256 verification, update, and uninstall options.
- No ads, analytics, telemetry, reporting, or app network access.

## Install or update

```bash
python3 install.py --serial TV_IP:5555
```

The installer fetches the latest stable release and verifies its checksum. The package ID is `com.jeremykenedy.rainforestcascade`. Select Rainforest Cascade in the TV screensaver settings after installing. To remove it, run `python3 install.py --serial TV_IP:5555 --uninstall`.

For manual installation, download `rainforest-cascade.apk` and `rainforest-cascade.apk.sha256` from this release and run `shasum -a 256 -c rainforest-cascade.apk.sha256` in the download directory.

This release requires Android API 23 or newer. The Fire TV test used Fire OS 11 / API 30. Physical Android TV and Google TV compatibility has not been device-tested. There is no upgrade requirement from a previous release.

The app's preview and settings screens and local ADB installer were tested on the Fire TV. Its Fire OS image did not expose the Dream manager shell service, so active system DreamService lifecycle testing was unavailable. The pre-existing screensaver component and enabled state were restored after the test.
