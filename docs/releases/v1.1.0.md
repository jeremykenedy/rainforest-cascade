# Rainforest Cascade 1.1.0

Three real moving waterfalls and a separate original sunrise flower garden replace the painted waterfall renderer. The garden animates falling water, foam, pond ripples, mist and local foliage; it is original rendered artwork rather than photographed footage.

## Upgrade guide

Update an existing 1.0.0 installation in place with the same package and production signer. Android API 23+, OpenGL ES 2 and H.264 decoding are required. The minimum API remains 23; no accounts, runtime downloads, migrations, environment changes or system-timer changes are needed. All seven preferences and their accepted legacy values remain supported. The environment picker adds `garden`. `canyon` now shows snowy Goðafoss footage rather than painted red cliffs.

Download `rainforest-cascade.apk` and `rainforest-cascade.apk.sha256`, then verify and install with an explicit serial:

```sh
shasum -a 256 -c rainforest-cascade.apk.sha256
python3 install.py --serial SERIAL --apk rainforest-cascade.apk
```

The guided installer can fetch and verify the latest stable release with `python3 install.py --serial SERIAL`. Open the app, choose a scene, use the remote's Preview button, then Back to settings. Select its DreamService in supported platform settings or through Fire TV Toolkit for idle use. The installer changes no selected Dream, timers or OS update settings.

A different signer cannot update an existing installation. Preserve the trusted original APK and signing identity; do not uninstall to bypass a mismatch unless deleting preferences is intended. Selecting another screensaver provides a reversible fallback. Android may refuse a version-code downgrade to 1.0.0; uninstalling to downgrade deletes local preferences. Scripted removal requires `--uninstall --yes --force`.

## Breaking changes

Package, signer, minimum API, provider endpoints and seven preference keys remain stable. Visual interpretations change with the replacement renderer: legacy `width=narrow` means Wide view, `curtain` means Balanced and `wide` means Close view. These uniformly change framing and preserve water/rock proportions; they do not change physical waterfall width. Speed now changes actual video playback. Night grades the daylight source; garden night does not change sunrise to a separately rendered nighttime environment. No stored-value migration is required.

## Major changes

- Licensed recorded forest, mossy stone and winter canyon waterfalls, plus an original sunrise flower garden.
- Offline 1920x1080 moving scenes with uniform framing, slow/natural/fast playback, day/night grading, added mist and sunlight shimmer.
- Garden includes independent water, pond, mist and foliage motion in a 16-second loop; the source plate is 1672x941, so 1080 output does not imply native 4K or extra photographic detail.
- Preserved remote settings, per-setting Random and randomize-all, stable host provider and native protected DreamService.

## Minor changes and fixes

- Offline source credits and full application license accessible with the remote.
- Photographic media provenance, adaptation terms and attribution bundled separately from Apache application licensing.
- Corrected 100 percent Java line/branch enforcement and actual source-formatting targets; installer coverage also enforces 100 percent.
- Refreshed native and physical screenshots and animated themed banners with reduced-motion alternatives.
- No app network permissions, analytics, tracking or runtime application dependencies.

## Verification

The production APK is 72,053,957 bytes with SHA-256 `88602f840deae1e9a7fa8de5b1dda03601c70d0d70399ab11262e1817e7de31f`. Certificate SHA-256 is `4818ad1fb9c91392b47d28fb84113640dfdc386d642890d980dd632637161400`.

API 34 emulator checks cover all scene framings, effects, playback speeds, remote settings/credits and actual test-Dream with Back. Physical AFTDEC012E/API 30 checks cover an in-place update preserving all seven preferences, remote Preview/Back, garden playback after 40 seconds settle, and an actual bound night DreamService with Back. The 33.588-second moving recording passed independent normal playback review, with changing water, foam, pond and mist and no abrupt observed loop jump. All seven app values and five system keys were restored exactly, including the prior asleep state.

A short SurfaceFlinger sample observed approximately 43.26 buffer presents per second. This is compositor evidence, not a decoded 30 fps or sustained renderer benchmark. Automatic idle activation across vendors, reboot/sleep-wake persistence, sustained thermal/power behavior and native 4K composition remain unverified.
